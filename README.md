# El Sayed Boutique, demo online store

Full demo of the El Sayed Boutique website: home, category pages, product pages, bag, checkout (orders go to WhatsApp), wishlist, about, contact and store map, delivery and returns, size guide, Arabic / English.

Products, prices and stock are sample data and photos are free Unsplash images; the live store will read products, stock and prices from Odoo.
